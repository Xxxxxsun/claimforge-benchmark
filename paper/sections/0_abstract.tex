Consumer-claim images create a practical failure mode for image forensics: a fraudulent image can be mostly a genuine photograph, with only a small plausible object inserted into a claim-relevant region. We introduce CLAIMFORGE, a benchmark design for localized AI object-insertion forgeries in restaurant and lodging imagery. CLAIMFORGE starts from real consumer-scene photographs, marks small insertion regions, generates localized edits such as pests, contamination, or damage, and splices only the edited object region back into the source image. This construction keeps nearly all source pixels unchanged and matches the real and forged images in post-processing, directly targeting shortcut-prone detectors that rely on global generative artifacts or file-format artifacts. The current repository snapshot contains 600 screened candidate source images, 297 complete restaurant edit slots, and 22 HunyuanImage-3 pilot generations; the median insertion box covers only 0.232\% of the source image. We define a two-task evaluation protocol requiring both image-level detection and pixel-level localization, and outline a baseline suite spanning manipulation localization, whole-image AI-generated image detection, diffusion-inpainting detectors, multimodal models, human inspection, and provenance.
